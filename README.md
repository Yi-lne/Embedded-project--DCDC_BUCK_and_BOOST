# DCDC升降压电源板项目

## 概述：

这是一个集成可调升压、可调降压以及固定降压 5V 输出的电源项目，兼有 ADC 外电压检测功能，利用 OLED 显示可调升压、可调降压及外电压检测的电压值。ADC 电压检测功能采用 STM32F103C8T6 系统板实现，STM32F103C8T6 系统板由固定降压 5V 输出电路再经 AMS1117-3.3 芯片降压供电。电源输入串联一次性保险丝，电源电路集成 13V 过压保护电路；ADC 外电压检测电路集成 33V 过压保护电路及防反接电路。可调 BUCK、可调 BOOST 芯片可由板上拨动开关控制启停。

## 说明：

1. 电源电压输入端口类型：5.5-2.1 规格 DC-005 母座

2. 电源电压输入范围限制：7V~13V（7V 为设计下限，更低输入未实测；13V为设计上限，实测最高输入为14V 左右可工作）

3. 可调降压电压范围（理论计算值）：1.23V~7.38V（实际测试为 1.22–7.36V 左右，板载电位器调节）

4. 可调升压电压范围（理论计算值）：13.2V~25.2V（实际测试为 13.69–25.8V 左右，板载电位器调节）

5. ADC 检测电路：

   - 计算分压电阻：R1 恒取 10K，R2 = R1 / ( Vmax / 3.3 - 1 )

   - 可调升压 Vmax = 25.2V，R2 取 1.3K；ADC 通道为 PA2

   - 可调降压 Vmax = 7.38V，R2 取 6.8K；ADC 通道为 PA6

   - 外电压检测 Vmax = 33V（为留有裕量，实际最高测 30V 左右），R2 取 1K；ADC 通道为 PA4

6. OLED 引脚：SCL -> PB1；SDA -> PB0（0.96 寸、4 脚 OLED）

7. 可调 BUCK 控制引脚（ON#OFF）受 PB11 和 PB10 控制：当 PB11 为高电平时（打开 BUCK_ADJ 开关），PB10 设为低电平以驱动 LM2596S-ADJ/NOPB 芯片；当 PB11 为低电平时（关闭 BUCK_ADJ 开关），PB10 设为高电平以关闭 LM2596S-ADJ/NOPB 芯片。

8. 可调 BOOST 控制引脚（EN）受 PA0 和 PA3 控制：当 PA0 为高电平时（打开 BOOST_ADJ 开关），PA3 设为高电平以驱动 LGS6302B5 芯片；当 PA0 为低电平时（关闭 BOOST_ADJ 开关），PA3 设为低电平以关闭 LGS6302B5 芯片。

## 软件设计：

固件基于 STM32F103C8T6 + HAL库，系统时钟 72MHz，主要功能：

- **ADC 采样**：ADC1 三通道扫描（PA6 可调降压、PA2 可调升压、PA4 外电压），连续转换 + DMA1_CH1 循环搬运到 `adc_data[3]`；上电先做 ADC 校准；关闭 DMA 传输完成中断，避免频繁中断打断软件 I2C。
- **电压换算与滤波**：按 3.3V 参考电压和分压比把 ADC 码值换算成实际电压，做一阶低通滤波（α = 0.2），四舍五入到 0.01V。
- **OLED 显示**：软件 I2C 驱动 0.96 寸 SSD1306，100ms 刷新一次，显示可调降压、可调升压和外电压；对应通道关闭时显示 `------`。
- **开关控制**：BUCK / BOOST 拨动开关经 EXTI（PB11 / PA0）触发 TIM2 / TIM3 的 20ms 单次定时器消抖，消抖后驱动芯片的使能引脚；BUCK 的 ON#OFF 低电平有效（PB10），BOOST 的 EN 高电平有效（PA3）；上电时同步开关状态，保证芯片状态与开关一致。
- **低功耗**：主循环无任务时进入 `__WFI()`。

## 实测记录与硬件改动：

1. 13V 过压保护：设计上由 13v稳压管（BZT52C13）触发 Q6三极管 关断输入 P-MOS。输入电压达到 14.02V 左右时，电源后级电路被断开。但 POWER_LED 由输入侧供电，过压时后级已断开、LED 仍然正常点亮，容易误判为整板仍通电；后续改版会把指示灯移到保护后级，或增加过压状态指示。
2. ADC 分压钳位稳压管：原设计在可调升压（D6）、可调降压（D5）、外电压检测（D7）分压节点各接一只 BZT52C3V3稳压管，作为 ADC 过压钳位。实测稳压管反向漏电导致分压节点电压偏低、OLED 电压读数不准，实际板已经拆除 D5、D6、D7。拆除后按分压比换算电压；此时 ADC 输入端失去钳位保护，需要注意避免过压。
3. ADC外电压检测电路的输入反接时，ERR_LED亮起（红灯），且OLED上显示的ADC外电压继续为0v，说明防反接电路有效。
4. BUCK ON#OFF 下拉电阻：原 R27（10K）把 LM2596S-ADJ 的 ON#OFF 持续下拉到 0V，导致开关控制失效。实际板已拆除 R27，拆除后可正常开关可调 BUCK 芯片。拆除后 ON#OFF 在 MCU 上电前处于浮空状态，后续改版建议增加上拉或上电时序控制。
5. 未测试：目前没有 1V 电源，电源电压输入7V 下限未实测；ADC外电压检测电路的过压保护理论限制为33v，但手头没有大于17V的设备，故没有测试实际过压限制值。
