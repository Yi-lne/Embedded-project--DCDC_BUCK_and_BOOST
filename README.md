# DCDC升降压电源板项目

## 概述：

​	这是一个集成可调升压、可调降压以及固定降压5V输出的电源项目，兼有ADC外电压检测功能，利用OLED显示可调升压、可调降压及外电压检测的电压值。ADC电压检测功能采用STM32F103C8T6系统板实现，STM32F103C8T6系统板由固定降压5V输出电路再经过AMS1117-3.3芯片供电。电源电路集成13v过压保护电路；ADC外电压检测电路集成33v过压保护电路及防反接电路。

## 说明：

1. 电源电压输入端口类型：5.5-2.1规格DC-005母座

2. 电源电压输入范围限制：<13v

3. 可调降压电压范围：1.23v~7.38v 

4. 可调升压电压范围：13.2v~25.2v

5. ADC检测电路：

   - 计算分压电阻：R1恒取10K，R2 = R1 / ( Vmax / 3 - 1 )

   - 可调升压Vmax = 25.2v，R2取1.3K；ADC通道为PA2
   
   - 可调降压Vmax = 7.38v，R2取6.8K；ADC通道为PA6
   
   - 外电压检测Vmax = 33v（为留有裕量，实际最高测30v），R2取1K；ADC通道为PA4

6. OLED引脚：SCL ->PB1； SDA -> PB0（0.96寸、4脚OLED）

7. 可调BUCK控制引脚（ON#OFF）受PB11和PB10控制：当PB11为高电平时（打开BUCK_ADJ开关），PB10设为低电平以驱动 LM2596S-ADJ/NOPB芯片；当PB11为低电平时（关闭BUCK_ADJ开关），PB10设为高电平以关闭 LM2596S-ADJ/NOPB芯片。

8. 可调BOOST控制引脚（EN）受PA0和PA3控制：当PA0为高电平时（打开BOOST_ADJ开关），PA3设为高电平以驱动LGS6302B5芯片；当PA0为低电平时（关闭BOOST_ADJ开关），PA3设为低电平以关闭LGS6302B5芯片。
